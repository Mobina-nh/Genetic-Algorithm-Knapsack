# Knapsack Problem Using Genetic Algorithm

## About
This project solves the Knapsack Problem using a Genetic Algorithm in Python.

## Features
- Initial population generation
- Fitness function
- Tournament selection
- Crossover
- Mutation
- Finding the best solution

## Technologies
- Python
- Random library

## How to Run
1. Install Python.
2. Download the project.
3. Run `knapsack_genetic.py`.

## Goal
To maximize the total value of selected items without exceeding the knapsack capacity.
